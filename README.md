Y8QWHU – Szkript nyelvek

Ez a projekt a Szkript nyelvek tantárgy keretében készült, a Git és a GitHub verziókezelési lehetőségeinek gyakorlása céljából.

A feladat célja egy Python-projekt létrehozása a PyCharm fejlesztőkörnyezetben, a Git-verziókezelés beállítása, valamint a projekt feltöltése egy nyilvános GitHub Repository-ba.

main.py – Egyszerű Python-program, amely egy üdvözlő üzenetet jelenít meg.

README.md – A projekt bemutatása és dokumentációja.

A main.py fájl megnyitása után a program a PyCharm fejlesztőkörnyezetben futtatható.
